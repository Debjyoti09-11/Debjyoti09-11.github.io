Validating data with SQL.

Before sign-off, I check that what reached the ERP matches the source. Run the sample check.

recon_pos_sales.sqlread-only
-- POS transactions vs ERP postings, by store
SELECT s.store_code,
       COUNT(p.txn_id)       AS pos_txns,
       COUNT(e.txn_id)       AS erp_txns,
       SUM(p.amount) - SUM(COALESCE(e.amount,0)) AS diff
FROM pos_txn p
JOIN store s ON s.id = p.store_id
LEFT JOIN erp_posting e ON e.txn_id = p.txn_id
WHERE p.txn_date = '2026-09-01'
GROUP BY s.store_code;
